# Landing Page — Kéfir Vital

Landing page profesional migrada a control de versiones, TypeScript y POO
como actividad de las sesiones 13–16 (AHD3-FE).

## Requerimientos

**Requerimientos funcionales:**
- El formulario de contacto valida nombre (mínimo 3 caracteres), correo
  (formato válido) y mensaje (mínimo 5 caracteres).
- Al enviar el formulario correctamente, se confirma la recepción al usuario.
- Las secciones de Beneficios, Productos y Contacto aparecen con una
  animación de entrada al hacer scroll (Intersection Observer).
- El menú de navegación enlaza mediante anclas a las secciones Beneficios,
  Productos y Contacto.
- La sección de Beneficios muestra 9 tarjetas con los beneficios del kéfir.
- La sección de Productos muestra 3 productos, cada uno con imagen, nombre
  y descripción.

**Requerimientos no funcionales:**
- La página debe ser amigable, intuitiva y funcional.
- El diseño debe ser responsivo (se adapta a pantallas móviles).
- El código debe estar tipado (TypeScript) y organizado con POO.
- El código debe estar bajo control de versiones (Git) y publicado en GitHub.

## Estructura del sitio

- Menú de navegación
- Hero (sección principal)
- Beneficios (9 tarjetas)
- Productos (3 tarjetas)
- Contacto (formulario)
- Footer

## Tecnologías

- HTML5 y CSS3
- TypeScript *(a integrar en la Fase 4)*
- Programación Orientada a Objetos *(a integrar en la Fase 5)*
- Git y GitHub

## Cómo ejecutar

1. `npm install`
2. `npm run dev`
3. Abrir la URL local que muestra la terminal
